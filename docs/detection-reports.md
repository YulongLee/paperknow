# PaperKnow 检测报告

两种报告共用 `dist/reports/report-document.mjs` 的 PaperKnow 品牌、元数据、结果摘要、表格、正文标注和 A4 打印样式。HTML 完全独立，不包含外部字体、脚本或远程图片；元数据与原文转义，页面声明 noindex 和禁止脚本的内容安全策略。

## 文本相似性报告

- 入口：免费查重 → 实际材料比对 → 查看报告 → 导出报告；工作台历史列表也可直接导出 HTML。
- 导出包含总览、章节统计、来源概览、全文标注、匹配片段对照、来源正文和计算口径。
- 保留既有确定性比对值，不改变算法和检测范围。当前只比较用户提供的实际正文；报告明确未检索在线数据库。
- 同一字符多来源命中只算一次；单来源命中不可相加。引用排除依据现有有限规则，需要人工核对。
- 正文高亮包含全部实际区间。对照卡每段最多 12 条、每份 HTML 最多 120 条；完整区间仍在 JSON 中，导出不会删改原始数据。
- 演示材料或演示模式始终标注为演示报告。

## AIGC 文本鉴别报告

- 入口：降 AI 率 → AI 文本鉴别 → 完成任务 → 预览 / 保存 PDF，或下载 HTML 报告。
- 只有状态完成、片段数量完整、Unicode 字符区间连续且覆盖送检长度的任务可以导出。
- 结果为长度片段的表达倾向与该标签的置信分，不是逐句判定，也不计算、平均或虚构全篇 AI 字符占比。
- 提交会话仍保留原文时，附加该次送检原文分段标记；历史任务不保存正文，刷新或切换任务后仅导出结果摘要，不使用当前编辑器文本冒充历史原文。
- 下载 HTML 沿用账户私有 OSS 成果保存与下载链路。开始、云文件保存后、完整下载响应读取后均核对原账户；账户变化或页面销毁则中断并清空预览。
- PDF 通过沙箱预览中的浏览器打印生成，保存到用户选择的位置，不声称浏览器打印自动上传 OSS。

## 范围

这次改动是报告版式和交付能力，不等于已接入联网查重或知网、万方、维普检测。报告编号用于 PaperKnow 记录定位，不宣称第三方认证、防伪验证或学校指定报告。报告不包含底层模型和服务商标识。

## 验证

`tests/detection-formal-report.test.mjs`、`tests/report-export.test.mjs`、`tests/report-highlight.test.mjs` 保证相似性证据、演示标识、安全转义和长稿上限。

`tests/aigc-report.test.mjs`、`tests/aigc-detection-ui.test.mjs` 保证结果语义、历史正文边界、预览打印、账户切换及下载延迟竞态。浏览器验收使用 localhost 模拟服务，不将模拟数据作为真实检测证据。
