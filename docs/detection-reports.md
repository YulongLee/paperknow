# PaperKnow 检测报告

## 2026年10月27日更新

当前入口为“论文检测”，包括论文重复率检测与论文AI率检测。下文早期实现记录中提到的免费入口、历史不存正文等描述，以本节当前行为为准。

- 等待界面共用 `dist/workspace/detection-progress.mjs`，提交、排队、运行时保留同一个状态栏，只更新真实任务状态与等待时间，不虚构百分比。轮询不重建结果区，不展示检索步骤、分块计数、局部标签和置信分。网络短暂失败继续读取原任务，不自动重复付费提交。
- 报告参考知网 PMLC 手册的基本信息、总览、分章统计、来源与全文标注结构，保留 PaperKnow 品牌及实际检测口径，不声称具有知网数据库或同等检测值。参考：[常州大学公开的知网使用手册](https://jjxy.cczu.edu.cn/_upload/article/files/da/1e/1b6c7b7d44a5b1f4c3f357160f8f/c534d48f-0c0d-49b6-bd75-aae8ef1c0456.pdf)。
- 相似性报告新增由实际区间计算的单篇最大文字相似比、单篇最大匹配字符、匹配段落数和最长连续匹配字符；来源编号可以定位到来源详情。同一原文区间内同一来源的重复命中先合并，主相似占比及原始证据不变。联网报告的去除引用和本人文献占比标记“未计算”，不显示为0%。
- AI报告按实际标签及连续原文区间展示疑似AI片段字符占比、疑似AI片段字符数、有效检测字符和送检字符。不能用置信分换算作者比例。失败时不展示局部表格或占比。已经归档的送检原文用于报告恢复；旧记录无原文时不附加当前编辑器内容。
- 两种新检测均优先使用对应套餐1次，否则500积分。完整有效结果成功后结算一次，失败或取消释放预占；读取、预览和下载不重复扣费。付费任务无试用每日次数限制，单次长度、并发及超时保护保留。已取消每次检测的勾选确认框。
- 报告使用账户私有OSS文件链路；下载前后复核原账户。HTML独立、无脚本；可以预览打印或另存PDF。检索覆盖说明放在报告末尾，不在检测过程中逐项呈现。

新增测试 `tests/detection-progress.test.mjs` 及两种检测UI回归用例，检查状态栏DOM身份稳定、过程隐藏、失败不展示局部结论、真实统计与来源定位。浏览器验收使用合成材料及模拟接口，不作为检测准确率验证。

## 原文定位与对照

原文定位补充：结果页展示前5条原文摘录并提供直接定位按钮；完整相似性报告按章节和段落列出全部实际命中位置，左右展示论文文字与来源对应文字，并提供安全来源链接。同一来源在同一原文区间的重复对齐只展示一次，原始匹配记录不变。

AI报告按保存原文的换行建立定位，标出落在实际AI标签片段内的原文段落。该定位不把片段标签提升为逐句判定，不生成或编造另一篇对照文章。跨度混合的段落定位到实际疑似片段的交集。短行特别多时最多生成300条点击定位，全文送检内容与实际标签仍全部保留，避免报告过大而无法保存。没有原文的历史记录不提供虚假的定位。

`tests/detection-original.test.mjs` 覆盖原文与来源对照、原始证据不变、Unicode与CRLF位置、跨片段段落定位及长报告体积。两种检测UI测试覆盖从原文摘录打开对应报告位置，过程中不新建付费任务。

报告预览保持原有严格沙箱。经安全URL校验的来源链接只在用户主动点击时，由父页面以 `noopener,noreferrer` 打开新窗口，当前报告不被替换；未变化的账户及页面上下文必须仍有效。浏览器验收覆盖来源打开、无来源Referer与原预览继续保留。

## 早期实现记录

两种报告共用 `dist/reports/report-document.mjs` 的 PaperKnow 品牌、元数据、结果摘要、表格、正文标注和 A4 打印样式。HTML 完全独立，不包含外部字体、脚本或远程图片；元数据与原文转义，页面声明 noindex 和禁止脚本的内容安全策略。

## 文本相似性报告

- 入口：免费查重 → 实际材料比对 → 查看报告 → 导出报告；工作台历史列表也可直接导出 HTML。
- 导出包含总览、章节统计、来源概览、全文标注、匹配片段对照、来源正文和计算口径。
- 保留既有确定性比对值，不改变算法和检测范围。当前只比较用户提供的实际正文；报告明确未检索在线数据库。
- 同一字符多来源命中只算一次；单来源命中不可相加。引用排除依据现有有限规则，需要人工核对。
- 正文高亮包含全部实际区间。对照卡每段最多 12 条、每份 HTML 最多 120 条；完整区间仍在 JSON 中，导出不会删改原始数据。
- 演示材料或演示模式始终标注为演示报告。

## AIGC 文本鉴别报告

- 入口：降 AI 率 → AI 文本鉴别 → 完成任务 → 预览 / 保存 PDF，或下载 HTML 报告。
- 只有状态完成、片段数量完整、Unicode 字符区间连续且覆盖送检长度的任务可以导出。
- 结果为长度片段的表达倾向与该标签的置信分，不是逐句判定，也不计算、平均或虚构全篇 AI 字符占比。
- 提交会话仍保留原文时，附加该次送检原文分段标记；历史任务不保存正文，刷新或切换任务后仅导出结果摘要，不使用当前编辑器文本冒充历史原文。
- 下载 HTML 沿用账户私有 OSS 成果保存与下载链路。开始、云文件保存后、完整下载响应读取后均核对原账户；账户变化或页面销毁则中断并清空预览。
- PDF 通过沙箱预览中的浏览器打印生成，保存到用户选择的位置，不声称浏览器打印自动上传 OSS。

## 范围

这次改动是报告版式和交付能力，不等于已接入联网查重或知网、万方、维普检测。报告编号用于 PaperKnow 记录定位，不宣称第三方认证、防伪验证或学校指定报告。报告不包含底层模型和服务商标识。
