# PaperKnow 首版范围

## 产品方向

PaperKnow 对齐 PaperRed 的公开功能范围，使用用户提供的蓝白视觉与自有品牌。先验收本地页面与交互，再逐步接入真实服务。

参考时间：2026-10-03。仅核对公开页面，未登录竞品账户；无法据此声称覆盖登录后全部功能。

## 公开功能参考

- https://www.paperred.com/ ：AI 写作、降重复率、降 AIGC、免费查重、PPT、科研工具、格式排版、AI 研读、简历。
- https://www.paperred.com/ai/dissertation ：题目、学历、字数、语言、资料、参考文献、大纲及下载的写作流程。
- https://www.paperred.com/check ：检测版本、文本输入、文件上传、检测报告。
- https://www.paperred.com/research/drawing ：图表类型、图表描述、生成记录。
- https://www.paperred.com/format/typesetting ：模板选择、文档上传、排版预览。

## 本次原型边界

| 功能 | 当前状态 | 后续正式能力 |
| --- | --- | --- |
| 首页与工具导航 | 本地完成 | 根据体验反馈调整 |

| 选题与开题 | 通用结构模板 | 学科化选题和开题内容生成 |
| 免费查重 / AIGC | 表单与报告结构演示 | 接入有授权的检测服务 |

| 导师修改 | 批注输入与任务模板 | DOCX 批注解析、逐条修改建议 |
| 格式排版 | 通用结构预览 | 校级模板库与 DOCX 排版 |

## 实现阶段建议

1. 页面体验验收：品牌、导航、布局、移动端、工具流程。
2. 核心写作闭环：认证、项目记录、资料解析、模型调用、真实引用、编辑与导出。
3. 检测与修改：检测供应商、批注解析、修改对照、异步任务与失败重试。
4. 排版、PPT、研读及科研工具逐项上线。
5. 用户提供服务器与真实域名后，落实部署、备份、密钥管理与监控。

不使用竞品的品牌资产、用户评价、用户规模、合作高校数量或质量保证作为 PaperKnow 的事实陈述。
