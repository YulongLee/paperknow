# 文档解析与内容安全服务

更新日期：2026-10-18。本页说明 MinerU 云端 PDF 解析和阿里云内容安全审核的接入边界，不能代替线上验收记录、第三方合同或实时可用性监控。是否开放以服务配置和工作台实际状态为准。

## 文件与同意范围

| 路径 | 当前范围 | 是否外发 |
|---|---|---|
| 浏览器本地提取与本地材料比对 | 按工具页面的格式、大小、页数限制 | 不因失败而自动转为云端 |
| 账户 TXT、DOCX 原件 | 每文件最多 2 MiB，沿用原有处理路径 | 上传到账户不等于提交在线 AI |
| 账户 PDF 原件 | 每文件最多 20 MiB，账户原件总配额仍适用 | 仅上传至本站私有对象存储 |
| MinerU 云端 PDF 解析 | 最多 100 页、200,000 字符 | 登录后明确同意，再发送所选原件及必要选项 |
| 在线 AI 输入／输出安全审核 | 启用审核的任务中选定输入、必要材料文本及准备交付的结果 | 交给阿里云内容安全服务；长文按服务限制分段 |

页面必须先说明第三方名称和所选文件，再取得云解析同意；不能预勾选、根据“本地没有提取到文字”直接外发，或把登录／保存原件当成该次同意。应保留粘贴正文、本地工具或暂不提交的选择。在线 AI 的确认说明同时披露相应内容审核。

MinerU 用于提取文字、扫描页、表格、公式和页码结构，不承诺 Word 原样版式恢复，也不替代用户对原文的合法处理权限。阿里云安全审核用于内容风险控制，不是学校查重、AI 字符占比、论文事实正确性或学术质量鉴定。公开页面说明服务商与用途，不展示内部模型名称、凭据或签名地址。

## MinerU 服务端流程

1. `POST /api/files` 保存当前账户原件至私有 OSS，校验类型、大小与账户配额。
2. `POST /api/document-parses` 接收 `fileId`、`idempotencyKey`、`consent: true`、`expectedUserId`；核对归属、登录账户及同意，创建可查询任务。
3. Worker 核对源文件哈希及真实页数，取得单文件上传任务并发送文件。上游任务号记录在数据库，凭据和上传签名地址不作为公开结果返回。
4. 根据已有上游任务查询状态。只接受成功业务码、匹配的资料编号、完整页数、受限压缩包与可核对正文；不把空白、缺页或截断结果标为成功。
5. 将 Markdown、包含正文和页码映射的结构化 JSON、原始 ZIP 保存至账户私有 OSS 成果目录。数据库保留任务、状态、归属、来源校验及成果索引；读取结果时经鉴权从 OSS 回读和校验。
6. `GET /api/document-parses/{id}` 返回当前账户任务与已完成结果，`POST /api/document-parses/{id}/cancel` 请求取消本站处理。用户仍需核对识别文字、表格、公式及来源页码。

`rawZip` 压缩大小上限为 20 MiB、解压总量为 40 MiB；结构化结果还有独立大小限制。不得直接解压至服务器目录，也不得直接渲染第三方 HTML、Markdown 中的不可信脚本或链接。OSS 不可用或结果未保存时不回退长期服务器文件或数据库 BLOB，不发布已完成状态。

提交中断或响应未知时，不能自动创建新批次重放。已确认任务可继续查询；需要用户重提时，应说明旧任务可能仍在上游处理或计量。取消本地请求不是上游终止、删除或退款的证明。本站未承诺 MinerU 零留存、不训练、固定处理地域或统一删除时限；运营需分别核对实际服务条款与删除支持。

## 阿里云输入／输出审核

使用独立开通的内容安全产品和明确配置的凭据；百炼模型调用密钥、短信签名或已有 OSS 权限不代表审核服务已启用。输入与输出采用对应审核场景，在原有任务预算与分段上限内处理。不可把风险标签或审核通过改名为论文检测分数。

审核应在适用的生成前及交付前执行；未配置、上游失败或无法判断时应按产品策略明确提示，不能默默绕过必需审核。安全原因、网络错误与模型执行失败应分别保留脱敏诊断。日志与审计不应包含凭据、签名 URL 或无必要的完整私人正文；第三方接收和留存范围应在任务确认与隐私说明中披露。

## 配置与凭据

服务器凭据只放受限环境文件或后续实现的加密配置存储，不提交到 Git、安装包、浏览器代码或公开报告。推荐各服务独立凭据与最小权限；普通 `service_settings` JSON 不能作为明文秘密仓库。

| 变量 | 用途 |
|---|---|
| `PK_MINERU_ENABLED` | `1` 才启用对应服务 |
| `PK_MINERU_API_TOKEN` | MinerU 独立 API Token |
| `PK_MINERU_BASE_URL` | 已验证的官方 API 地址，当前为 `https://mineru.net/api/v4` |
| `PK_MODERATION_ENABLED` | 内容安全服务启停 |
| `PK_MODERATION_ACCESS_KEY_ID` / `PK_MODERATION_ACCESS_KEY_SECRET` | 显式授权的独立阿里云审核凭据 |
| `PK_MODERATION_ENDPOINT` / `PK_MODERATION_REGION` | 已开通产品的接口与匹配地域配置；不是整个资料流的固定地域保证 |

可使用 `/etc/paperknow/mineru.env` 等独立受限文件，但只有服务单元或启动器明确加载时才生效。不要因为新增文件就宣称站点已读取配置。轮换凭据与开关前核对在途任务、旧批次查询、供应商权限和预算；不通过重放任务测试凭据。

## 运行与回退

当前部署使用单个 `paperknow.service` 进程管理数据库和 Worker，发布先停止旧进程再启动新进程；不能同时启动第二个连接同一数据库的 Worker，横向扩容前需增加分布式任务租约。排队领取使用状态比较更新；已确认批次的查询、下载网络错误会读取同一批次重试，受 30 分钟总时限约束，绝不自动重放提交或上传。失败、取消产生的新成果有删除账本，空闲时按节流补偿，已有去重成果不在删除范围。

独立环境文件设为 root 所有、0600，并由服务单元加载；验收后仅重启 PaperKnow 服务。Nginx 只为本站 `/api/files` 放宽受认证请求到 28 MiB 并关闭请求落盘缓冲，应用仍执行 20 MiB 文件限制。回退时恢复前一发布目录与配置；保留已产生任务和 OSS 对象供核对，不通过清空数据库或重放任务完成回退。

## 发布前的实际验收

- 同一份合成 PDF 包含文字层、扫描页、表格、公式；页数、正文、结构及所有实际保存成果可回读验证。
- 未确认、未登录、跨账户读取、超限、加密或损坏 PDF、缺页、供应商失败及 OSS 异常均有真实错误状态。
- 重复点击只绑定原有任务；未知提交不会自动重放；取消不会发布完成结果或误删其他任务去重成果。
- 内容审核分别覆盖允许内容、阻断／复核结果、上游超时及凭据失效，不把模拟测试当作已发送用户材料的证明。
- 公开帮助、隐私、功能状态、上传界面与下载结果中的限制和处理路径一致。独立供应商接口小样通过不等于所有工作流已集成、上线或全领域验收。
