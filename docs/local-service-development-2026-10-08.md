# PaperKnow 本地服务开发进度

本批从浏览器原型推进到账户、数据库、文件及任务的真实服务端闭环。旧本地工具保持可用，不自动迁移或覆盖浏览器内容。服务入口：`http://127.0.0.1:5173/service.html`。

## 本地运行

需要 Node >=25.2（当前使用 Node 内置 SQLite；该接口仍带实验性提示）。首次安装依赖后 `npm start`，默认仅绑定 `127.0.0.1:5173`。

数据库位于 `.data/paperknow.sqlite`，用户原件作为 BLOB 保存于数据库；`.data/`、`.env` 均忽略提交。不要将数据库、密钥或论文原件上传 Git。数据只跨当前服务的浏览器会话共享，并非已经部署到云端。关闭服务后，数据库文件仍保留。

模型配置参照 `.env.example`，将自己有权限使用的接口、密钥、模型填写在本地 `.env` 后使用 `node --env-file=.env server.mjs`。接口必须为 HTTPS 或本机 HTTP，格式为 chat completions。没有配置时，AI 提交被禁止，不产生模拟输出。配置后提交会把正文及要求发送给所选服务商。代码默认不启用产品扣费，但第三方模型供应商可能收费。失败请求可能已消耗第三方额度，不能依据没有成功记录推断完全未收费。

管理员不通过公共注册自动获得权限。由本机维护者对已经注册的指定账户运行 `npm run admin:promote -- 已注册邮箱` 后，该账户出现管理后台入口。此命令会改变权限，不应在公共 Web 接口中开放。验收未给真实或测试账户执行管理授权，只在独立临时数据库中测试权限。

本地服务暂不支持密码找回，请自行保管测试账号；不复用聊天中曾提供的其他网站密码。尚未接入邮箱验证、公开注册防机器人、多因素认证和正式密码重置，不能直接作为公开商业网站上线。

## 数据和任务限制

- 文件最大 2MB；单账户原件总量 50MB；支持 UTF-8 TXT、DOCX、文本 PDF，PDF 最多 100 页。扫描 PDF 报错要求 OCR。
- DOCX 解压总量最大 30MB，最多 3000 个包条目；正文最长 200,000 字符。解析和比对在限制内存的独立线程运行，60 秒超时，取消会终止线程。
- AI 正文最多 6000 字符，要求最多 2000；模型响应最大 1MB，90 秒超时，不自动重试可能产生费用的请求。
- 比对正文和单个来源最多 8000 字符，API 接受 1～5 份实际材料，当前前端提供单来源表单。来源标题、作者、年份、DOI、URL 与正文快照保存到报告；它们是用户提供信息，未经外部核验。
- 单账户最多 3 个未结束任务，单本地进程按顺序处理。不支持多个实例共同抢同一个数据库；正式部署应改为带租约的任务系统。
- 重启将正在处理的任务标记失败，而非盲目重放；已排队任务继续。手动重试会保留编号并增加执行次数。
- 没有付费全文抓取、外部查重分数、语义相似度或自动 AI 检测率。相似度仅由实际材料的确定性文本算法计算，不能解释成知网、万方、维普结果。

## API

所有数据接口要求登录；POST 要求同源 Origin，Cookie 为 HttpOnly/SameSite=Strict。管理员接口由服务端判断角色，所有数据读取/写入按用户约束，不通过前端传入用户编号授权。

| 接口 | 用途 |
|---|---|
| GET /api/capabilities | 真实服务配置状态，不返回密钥 |
| POST /api/auth/register、login、logout；GET /api/auth/me | 账户与会话 |
| GET/POST /api/projects | 项目列表与创建 |
| GET/POST /api/files；GET /api/files/:id/download | 私有原件与下载 |
| GET/POST /api/jobs | 真实队列、幂等提交 |
| POST /api/jobs/:id/cancel、retry | 取消、失败重试 |
| GET /api/results、/api/results/:id | 成果及原始输入/结果 |
| GET/POST /api/results/:id/revisions | 人工编辑版本，原文和模型建议不可覆盖 |
| GET /api/usage | 真实返回的 Token 数据，无产品扣费 |
| GET /api/products、/api/orders | 预览目录及现有订单；购买创建返回未启用 |
| GET/POST /api/feedback | 保存到本机服务的私有反馈 |
| GET /api/admin | 管理员专属概览 |

## 验收

自动测试包含账户隔离、登录/退出、来源校验、幂等、取消、失败重试、重启、实际 DOCX 提取、无文本 PDF、模型响应桩、版本和用量、管理员权限、未配置 AI/支付拒绝。模型测试桩仅运行于独立临时服务，不是产品展示或真实 AI 调用。

浏览器使用独立 `example.invalid` 测试账户与自建文本，验证注册、保存项目、上传原件、后台解析、查看成果、材料比对及来源对照、JSON 导出。原工作台资料未导入服务端、未覆盖。桌面和手机截图保存在本目录。测试账户资料保存在被忽略的本机数据库中，验收结束后已撤销该测试账户的会话，用户可自行注册。

页面内确认保护、Escape 保留输入、提交后未配置 AI 按钮保持禁用、成果编辑版本保存另有界面回归测试。旧测试页的原生确认弹窗曾导致浏览器自动化卡顿，新版本已替换为 HTML dialog；替换后的保护通过独立 DOM 交互测试，尚待浏览器解除旧弹窗后复测。

最终验证：完整自动测试 112 项通过，最新正文原样保存调整后后端 13 项复测通过，语法检查和差异空白检查通过。手机 390×844 下七个服务页面未发现整页横向溢出；本机服务重启后项目、原件与成果保持。
