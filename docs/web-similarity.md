# 论文相似内容预检查

本服务使用模型联网搜索取得候选链接，读取实际可访问的公开网页正文，再用确定性的文字比对生成标注与来源。模型输出、搜索摘要、文献题录、无法读取的网页均不是匹配证据，也不能用于生成相似占比。

## 处理与范围

用户提交 DOCX 提取出的正文后，服务保存私有输入并排队；当前单次最多 20,000 字符、300 个段落。系统从正文选取最多 12 个片段检索，每个长段中的抽样窗口分布在不同位置；它不是对所有段落和句子的穷尽检索。按查询轮流选取最多 24 个候选来源，安全读取正文后，完整送检正文与本次实际取得的正文进行文字匹配。报告中的相似占比是匹配字符合并去重后占参与比对字符的比例，只适用于本次资料集合，不能解释为全网或全部文献的重复率。未查得匹配也不能证明不存在相似内容。

当前只读取公开 HTML 和纯文本网页，不解析搜索返回的 PDF，也不访问登录或付费内容。暂未对接 PMC 的全文接口：其授权、全局限流和真实可达性尚待验证；Crossref 和 arXiv 题录不能当作全文。不得声称覆盖知网、万方等封闭数据库或输出这些平台的检测结果。未取得任何可比正文时不得生成零匹配报告；部分来源读取失败须保留范围限制。

匹配完成后，可使用现有模型为最多 5 个经过原文核验的命中段落生成简短修改建议，属于本次检测，不额外扣站内积分。模型不会改变原文、来源、匹配区间或相似占比；建议未能生成时仍保留比对报告。需要更多修改可按报告进入独立计费的降重流程。AI 率报告的逐句编辑提示目前是基于规则生成，不代表模型已经提供逐句生成或判定。

## 任务与费用

检测按现有后台计费规则预占套餐或积分，成功后结算，失败或取消释放；试用限额仍依服务配置执行。请求编号保证网络重发不重复创建任务；相同输入的进行中任务或 24 小时内完成报告可复用。失败或取消后，用户主动发起带新请求编号的提交可以创建新任务；服务中断或上游请求结果未知时不会自动重放可能计费的检索。重复的显式请求可能发生新的供应商调用。

输入和结果通过账户私有 OSS 保存；服务重启时正在处理的任务标记中断并释放预占，不自动再次检索。公开网页读取限制响应大小、重定向、连接地址和超时，不携带用户凭证。模型凭证不返回给浏览器。

## 配置与测试

`PK_WEB_SIMILARITY_ENABLED`、`PK_WEB_SIMILARITY_MODEL`、`PK_WEB_SIMILARITY_URL`、`PK_WEB_SIMILARITY_KEY` 和 `PK_WEB_SIMILARITY_WORKSPACE_ID` 使用现有服务端配置；来源检索仅使用允许的百炼 HTTPS 端点。可通过 `PK_WEB_SIMILARITY_ADVICE_ENABLED=0` 关闭建议；默认启用时也需要现有模型配置满足受信端点与模型要求。费用、每日免费额度及单次字符限制以后台配置和接口能力为准。

在隔离环境运行 `node --test tests/web-similarity*.test.mjs tests/web-query-long-paragraph.test.mjs tests/detection-paragraph-review.test.mjs`；相关来源、扣费和 AI 检测测试还应随集成运行。模拟测试不能证明线上检索覆盖、模型准确率或第三方全文接口可用。
