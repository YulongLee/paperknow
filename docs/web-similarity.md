# PaperKnow 公开来源查重（试运行）

## 已实现的路径

`/workspace.html#category/detection?view=web` 为默认联网查重入口；`?view=local` 保留浏览器内自备材料比对。联网功能使用已有百炼账户进行候选来源检索，没有购买或调用第三方查重检测接口。

账户确认和显式同意 → 私有 OSS 保存输入 → 持久任务排队 → 对最多 3 个真实正文片段强制联网检索 → 从供应商结构化 `search_info.search_results` 取得候选链接 → 安全读取最多 8 个公开网页 → 在受限工作线程内与本次参与检测的全文进行确定性文字匹配 → 私有 OSS 保存结构化报告及独立 HTML → 账户任务与成果入口恢复。

模型回复、搜索摘要、模型自行写出的 URL 均不作为匹配证据，模型也不生成相似百分比。沿用现有 Unicode NFKC、小写、字母数字规范化、连续至少 16 个规范化字符精确匹配算法；匹配区间映射回原文位置并合并去重。同一字符命中多个来源只计一次。参考文献、目录等解析排除章节不计入分母。当前不自动扣除规范引用，不进行语义重复计分。

## 范围与限制

- 单次最多 20,000 个 Unicode 字符，最多 300 个正文段落。最多选取 3 个有代表性的片段，不是逐句穷尽检索；每页取得的正文最多 50,000 个字符。
- 实际取得的来源与参与检测的全文比对，而不只是比对用于搜索的片段。报告列出抽样段落数、检索数、候选数、取得和失败来源数及其 URL。
- 本期只读取 HTML / 纯文本公开网页；PDF 来源、登录、付费正文、访问验证以及取回失败的来源均不作为已核验正文。用户上传的 PDF 是另一条现有解析流程，不等于可读取网络 PDF 来源。
- 完全没有取得来源时任务失败，不发布 0% 或“通过”结论。部分失败可出具范围受限报告；零文字命中只说明在本次实际取得的来源内没有匹配。
- 不覆盖封闭学校数据库，也不承诺与任何指定学术平台的检测结果一致。报告为 PaperKnow 自有公开来源比对报告。
- HTML 保留用户送检全文标红；网页证据每卡最多 240、每来源最多 1,200、整份报告最多 5,000 个 Unicode 字符，省略有标注，不附录抓取网页全文。完整匹配区间与来源快照保留在私有结构化报告中以便核对。

## 费用与恢复

试运行暂不扣科研积分。每账户每天最多 3 份、全站每天最多 40 份；单次最多 3 次检索。每日按北京时间计算，并在外部请求前持久记录检索尝试，跨日积压任务仍受每日最多 9 / 120 次检索约束。供应商 Token/联网调用可能计费，预留次数不等于供应商结算金额；未知用量保存为未知。

同一请求编号重复提交只返回原记录。相同正文在 24 小时内已发送外部请求时不自动重放；尚未外呼的失败或取消任务可用新的明确提交重试。任务中断、重启或响应未知不会自动再次执行可能收费的搜索。取消不会证明供应商已停止计量。

## 配置与隔离

`PK_WEB_SIMILARITY_ENABLED=1` 启用；`PK_WEB_SIMILARITY_MODEL` 默认使用 `qwen3.8-flash`。专用 URL、Key、业务空间可通过 `PK_WEB_SIMILARITY_URL`、`PK_WEB_SIMILARITY_KEY`、`PK_WEB_SIMILARITY_WORKSPACE_ID` 配置；未填写时继承现有服务端模型接口、密钥和业务空间，不继承不支持联网的任意模型名。公开页面不暴露具体模型与密钥。

仅官方百炼 HTTPS 端点可接收凭证。新模型通过原生多模态流式接口取得真实来源，设置 `enable_search`、`forced_search` 和 `enable_source`，不自动重试。

网页读取校验所有 DNS 地址并固定连接，逐跳检查重定向；拒绝私网、云元数据、非标准端口和敏感签名地址，不发送 Cookie 或鉴权凭据。10 秒、1 MiB、最多两次重定向，不执行网页脚本或模型指令。

输入与报告文件只写账户私有 OSS，SQLite 保存任务、索引和摘要。失败或取消后的本次新文件具有持久清理索引，补偿失败由维护任务继续；完成后清理输入副本，保留报告。未完成报告和内部输入不发布到成果文件列表。报告读取最多两路并发，每账户每分钟最多 20 次。报告下载前后复核账户，账户变化会使本次页面实例永久失效并隐藏原正文与预览。

官方调用说明：<https://help.aliyun.com/zh/model-studio/web-search>

## 验证范围

单元与接口测试覆盖确定性匹配、无来源不能输出零分、部分失败、同意/账户/来源边界、幂等、取消、重启不重放、日额度、OSS 失败与清理、报告并发、联网响应校验、SSRF 及前端跨账户竞态。

真实百炼候选来源调用和公开政府网页正文读取均已验证；Computer Use 的本地端到端验收采用合成文本、合成来源及内存 OSS，不能替代线上真实来源验收。最新部署及线上验收证据另存于 `outputs/web-similarity-20261019/`。
