# PaperKnow

蓝白风格的论文与科研平台，本地前端体验版。

## 本地运行

使用 Node.js 22.13+ 或 24+：

```sh
npm install
npm run dev
```

首页：http://127.0.0.1:5173/  
工作台：http://127.0.0.1:5173/workspace.html  
学术相似性预检：http://127.0.0.1:5173/precheck/

服务仅监听本机。`npm run build` 打包本地文档解析依赖，`npm run check` 检查脚本，`npm test` 检查计分算法。

## 首页

首页采用确认的蓝白商业化设计：首屏产品示意、八个工具入口、三个可打开的成果示例、三步流程、功能开放状态、数据处理说明与常见问题。写作及工具操作统一进入工作台，查重进入本地比对页面；不再在首页提供另一套写作表单。登录仅设置本地昵称，尚未开放真实账户、计费或在线 AI 服务。旧 `?tool=`、`?draft=` 与 `#writing` 链接会转到对应工作台。

## 工作台

按确认的蓝白设计稿实现商业工作台：工作空间、论文与科研、个人与服务三组导航，保留六项写作任务导航。概览采用任务优先结构：六个常用入口、新建任务选择窗口、上传用途选择、继续研究、带分类的最近成果、当前任务状态和简洁服务说明。账户入口集中到头像菜单。继续研究根据真实保存内容显示当前阶段，不推断其他阶段完成情况；相同项目、类型和内容的成果合并展示，全部保存记录仍在成果列表保留。

项目页提供卡片/列表切换、真实状态数量、项目类型和手动研究阶段、关联成果分类统计、最近保存记录、名称/研究说明搜索、最近活动/创建时间/名称排序、归档恢复与备份导出。视图和排序偏好保存在当前浏览器；旧项目没有阶段时保持未设置，不推断完成进度。新增项目创建、编辑、项目详情、创作及报告关联；成果列表支持分类、标题搜索、文本导出与关联调整；任务中心记录实际保存操作和本地文本比对。账户菜单提供本地资料、安全状态、会员用量与订单入口；设置支持默认学段/专业、列表密度、字号及 JSON 工作空间备份导出。帮助页面支持反馈文本导出，不自动发送。项目、资料、设置和任务使用浏览器本地存储，报告仍使用 IndexedDB；清理浏览器或换设备不会自动恢复。

论文写作提供类型选择、学段、学科、题目、研究要求、Word/PDF/TXT 参考材料本地解析、示例预览、大纲模板生成、编辑、草稿保存与 TXT 导出（带复制备用入口）。未生成大纲也可保存表单草稿；参考正文和要求随草稿恢复。

18 个工具入口，覆盖选题、开题、综述、写作、修改、检测、阅读、检索、翻译、排版、答辩、投稿、绘图与简历。工作台内提供分类、搜索、最近记录，以及可编辑、保存和导出的本地结构模板。科研绘图可按输入数据生成并导出 SVG 柱状图。AI 改写、翻译、AIGC 检测、在线检索等尚未接入实际服务，页面明确标示体验状态，不提供虚构结果。

## 学术相似性预检

- DOCX（Mammoth）、文本型 PDF（PDF.js）、UTF-8 TXT 在浏览器内解析，支持拖拽和粘贴。
- 解析预览与检测章节选择；目录、参考文献、致谢、附录默认排除。
- 内置三份明确标注的虚构演示材料；可添加有权使用的实际对照正文及作者、年份、DOI、URL。
- 对真实材料执行确定性连续文本比对，合并匹配区间，计分不会重复计算相同字符。
- 总相似度、有限引用规则排除后的相似度、字数、章节指标、来源排名、逐段标记与来源对照。
- 章节、来源、引用筛选及正文搜索；规则修改提示、手动修改并保留原报告。
- IndexedDB 报告记录与来源材料；HTML / JSON 导出、浏览器打印保存 PDF。
- 计划数据源状态页、计算口径和使用帮助；桌面及移动端布局。

**本版只对本地材料进行比对，未连接全网学术检索、语义模型、AI 服务或服务器任务队列，不等同于知网、万方、维普。** 没有来源时不会生成重复证据。0% 仅说明当前材料中未发现符合规则的文本匹配。

本地算法规范化 Unicode、大小写、标点与空白，使用 12 字符指纹召回并扩展连续相同区间，至少 16 字符才计入；字数以原文 Unicode 字母和数字字符计数，匹配区间先合并。英文按字母计，不等同 Word 的词数。未接入模糊或语义匹配。引用识别目前仅支持与演示参考文献一致的中文引号 + 编号形式，其他情况必须人工核对。

扫描 PDF 暂无 OCR，旧 DOC 请转换成 DOCX；PDF 版式复杂时请核对正文顺序。本地限制为 50MB、150 页 PDF、80,000 有效字符；最多 10 份用户对照材料，每份 20,000 字符。

## 目录与数据

- `dist/`：首页与预检页面；`dist/precheck/engine.mjs` 为独立计分模块。
- `src/precheck/parsers.js`：文档解析入口。
- `scripts/build.mjs`：解析依赖与 PDF worker 打包。
- `tests/`：算法测试与自建 DOCX/PDF 解析测试文件。
- `docs/ui-reference.png`：用户视觉参考。
- `server.mjs`：本地静态服务。

预检正文、报告及对照材料存储在当前浏览器的 `paperknow-precheck` IndexedDB；可通过页面删除。旧版本保存的大纲仍可从工作台恢复，昵称仍保存在本地。不要仅依赖浏览器保存重要论文，应导出备份。删除材料不改变已生成报告中的来源快照。

正式后台、账户体系、在线数据源、语义与 AI 模型、权限和部署仍待后续开发。本仓库不保存密码或私钥。

文献与研读页采用文献库工作空间，支持手动添加元数据、关联项目与标签，单份 DOCX / 文本型 PDF / TXT 导入及正文阅读。阅读状态由用户手动标记，打开正文仅记录最近打开时间；正文、摘要、仅元数据三种材料范围分开展示，不保证提取文本完整，不联网验证 DOI 与 URL。每篇可保存 100 条手动笔记并导出 TXT；综述入口仅导出用户选定文献的元数据、已有笔记与待填写的对照框架，不生成研究结论。在线检索、AI 研读和翻译尚未接入。

文献及笔记存放在当前浏览器 `paperknow-literature` localStorage，原始 PDF / Word 文件不持久保存，无 OCR 或原版 PDF 阅读器。单文件上限 50MB、正文上限 200,000 字符，文献库最多 200 篇，实际容量受浏览器配额影响。支持独立文献 JSON 备份和恢复，每次导入最多 200 篇，导入先完整校验，已有编号跳过且不覆盖，同名不同编号保留；工作空间总备份也包含文献。请及时导出，当前不提供云同步。

“我的成果”提供写作、文献、检测与演示分类，按标题或项目名称搜索，按项目筛选和按更新时间、创建时间、名称排序；同名记录独立保留。可继续编辑、查看报告、调整项目关联和查看成果信息。草稿导出 TXT；查重报告通过共享导出模块生成 HTML 或 JSON，PDF 从报告页打印保存。PPT 模板仅为演示提纲，不冒充 PPT 文件。成果页可导出完整本地工作空间备份，未接入云端同步。

任务中心使用真实本地保存记录与 IndexedDB 报告，支持状态、任务类型、所属项目、时间范围和关键词组合筛选，按最近记录时间排序。详情以侧边抽屉展示任务编号、输入文件、关联项目、实际操作记录和报告统计，并提供成果入口。当前没有在线队列、百分比进度、取消、重试或费用；不填充模拟任务，不补造执行阶段。保存操作沿用每份成果最近一条记录，已有独立同名记录保留，普通更新不生成新的处理任务。

论文写作页提供“填写研究信息 → 确认大纲 → 分章节写作 → 编辑与导出”流程。目标字数、研究方法、导师要求与材料用途随草稿保存；当前支持一份 DOCX/PDF/TXT 参考材料，本地解析状态、正文核对和移除均可用，但材料不会自动参与生成。示例大纲不可编辑或导出；生成的结构模板可修改并确认，随后手动逐章填写正文。修改大纲后保留被移除章节中已有正文，并标记待核对。正文与大纲分别保存，恢复已有记录时保留旧字段；TXT 正文导出只包含已填写的章节。当前需要主动点击保存，不提供自动保存或在线 AI。

修改与润色提供导师意见修改、学术润色、论文降重和降 AI 率四类手动工作流程。可导入一份 DOCX / 文本型 PDF / TXT，粘贴正文，或复制已有成果；原成果不覆盖。正文按空行分段，逐段编辑、记录意见和修改说明，修改被明确采纳后才进入导出稿，再编辑该段会取消采纳状态。意见是否解决由用户单独确认，不由采纳状态推断。文本差异采用共同前后缀标记变化区间，不代表相似性检测。

修改稿随项目关联保存到 `paperknow-drafts`，可从我的成果、项目和最近修改继续打开；原始导入文本不可编辑，每次保存新增版本，恢复时先保存当前稿，再新增恢复版本。最多 50 个版本，不自动清理历史；浏览器配额不足时会提示保存失败。离开未保存的稿件会提示确认，当前没有自动保存或云同步。支持采纳稿 TXT 导出、完整修改记录 JSON 导出，以及工作空间总备份；独立修改 JSON 目前仅导出，不提供导入恢复。单文件 50MB、150 页 PDF、全文 100,000 字符、500 段、单段 20,000 字符。不保留 Word 排版、批注或原始文件，无 OCR。AI 修改、在线降重与 AI 检测未接入，不生成修改建议或任何推測的重复率 / AI 率。

论文检测工作空间提供上传、拖拽、粘贴 / 核对正文和复制已有成果；关联项目与学段后，使用共享解析与确定性比对模块确认章节、运行本地比对、取消、保存并打开交互报告。目录、参考文献、致谢和附录固定排除，其他章节可勾选，空范围禁止提交。全文限制为 80,000 个有效字符、原文 200,000 字符；支持 50MB DOCX / UTF-8 TXT / 文本型 PDF（最多 150 页），无 OCR。

本工作空间只使用 IndexedDB 中用户实际提供的对照材料，默认不加入演示语料；没有材料时不运行、不生成重复率。添加材料需提供实际正文并确认使用权限，来源 URL 和 DOI 仅校验格式，不联网核验。进度来自实际段落完成数量；报告保存失败时提供会话 JSON 导出，不伪称已保存。新报告保存项目关联，最近报告支持标题 / 项目筛选和 HTML 导出；历史中的演示报告单独标注。报告页重新检测沿用原报告的材料快照与项目关联，不自动扩充演示来源。未提交的输入仅驻留当前页面会话，刷新后需重新导入；报告和来源在当前浏览器保存。AI 率检测禁止提交，全网检索、语义服务与正式收费后台尚未接入。

PPT 创作工作台（本地）：支持毕业答辩、开题、课题和文献汇报；上传 DOCX/PDF/UTF-8 TXT（50MB、PDF 150 页以内）、粘贴材料或复制已有成果。正文最多 80,000 字符，创建 6–30 页结构大纲；当前不会自动提炼、翻译或补造结果，页面保留明确的待补充提示。三种模板可预览，页面标题、正文和演讲备注可编辑，支持新增、移除、上下排序，保存到“我的成果”并关联项目。旧版 PPT 提纲仍可读取，不改写原有论文成果。

PPTX 使用本地打包的 PptxGenJS 导出 16:9 演示，文字为可编辑文本框，包含演讲备注。导出内容来自用户编辑的页面；浏览器预览与 PowerPoint 的字体和换行可能不同，长文本会缩小字号，需打开后核对。单页标题 120 字、正文 1,400 字、备注 3,000 字，最多 30 页。PDF 入口下载可打印 HTML，需打开后自行选择打印保存 PDF；另可下载 TXT 和 JSON 备份。JSON 是文稿数据备份，本页暂未提供导入恢复。没有云端、模型、图表自动生成或收费服务。未保存的修改离开或刷新会提示；解析与导出期间阻止切换路由。存储失败不会显示保存成功，请使用备份下载。
