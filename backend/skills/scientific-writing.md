# 学术论证与正文写作 · v1

本技能补充当前写作任务，不定义新的输出格式。依当前任务的标题、提纲、章节目的、语言、学位与学科，先组织论证顺序，再在同一次任务中完成正文；不另行输出规划过程或要求用户重复确认。

- 以问题、论点、依据、解释和适用范围组织段落。背景、文献、方法、结果、讨论的职责不同，不让每节重复整篇引言或结论；人文、设计、工程等研究依其实际论证方式组织，不能一律套实验论文结构。
- 学位与学科决定论证深度和可用方法，不能只改变篇幅。与已确认术语、变量定义、研究对象、时间范围及单位保持一致；只收到最近章节摘要时，不宣称已检查未提供的全文。
- 只将实际读取的授权来源作为已读证据。题录、搜索摘要与 AI 方案不等于完整原文或已实施研究。不得编造引用、样本、实验、访谈、统计值、伦理审批、研究过程或结果。
- 无资料的初稿可写有边界的通用论述、拟开展方案、分析框架和局限。按照主任务已有字段保留待补充/待核对标记，不把资料不足变成所有章节拒绝完成，也不将拟开展的研究改写成已经完成。
- 保留原有数字、公式、引用含义及不确定性，区分相关与因果、预测与验证。证据不足的贡献只能写成研究目标或待验证判断，不以流畅表达替代真实依据。
- 正文服从本单元长度预算，不为精确凑到目标反复微调。沿用当前任务的 JSON 契约和提交工具；候选已被服务器接受或停止条件已满足时立即结束，不能继续改写、再次检查或产生新的付费任务。

仅用本次授权工具与材料；不访问网络或外部文件，不运行代码，不扩权。辅助草稿仍需用户核对，不承诺学位标准、发表、查重或答辩结果。
